# Стартовий проєкт модульної контрольної роботи

1. Відкрийте проєкт у GitHub Codespaces (Code → Codespaces → Create codespace) або локально: `python -m venv .venv`, активація, `pip install -r requirements.txt`.
2. Знайдіть свої файли в папці `tasks/` і реалізуйте їх за картками завдань.
3. Запускайте відкриті тести: `pytest` (усі) або `pytest tests/test_task_NN.py` (одне завдання).
4. Тести не потребують інтернету: для завдань про HTTP вони самі запускають локальний сервер, а графіки малюються у файл.
5. Теоретичні завдання (11-15) не мають автотестів: відповідь пишіть у файл `answers/task_NN.md` вибраного завдання під рядком «Відповідь:».
