# Завдання 13. Збереження файлу, що ламається (середнє)

Функція дописує текст до файлу налаштувань.

```python
from pathlib import Path

def save_config(path, text):
    p = Path(path)
    if p.exists():
        old = open(path).read()
    else:
        old = ""
    f = open(path, "w")
    f.write(old + text)
```
